  - `150 Chaos`: Tech Stack Holy War Swarm (`🦀`, `🚀`, `502 Bad Gateway`, `npm ERR!`)

## ⚡ Quick Deploy (Zero Build Step Needed)
1. Upload `index.html` (and optionally `vercel.json`) to a new GitHub repository.
2. Enable **GitHub Pages** (`Settings → Pages → Deploy from branch: main`) OR import the repo into **Vercel** / **Netlify** for an instant live URL.
